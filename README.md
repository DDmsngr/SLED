# 🛷 SLED — GPS Трекер с Фото-метками

Flutter приложение для Android 12–14.

## Возможности

- 🗺️ Запись GPS-трека в реальном времени на карте OSM (оффлайн)
- 📸 Съёмка фото с привязкой к GPS-координатам и времени
- 📊 Статистика: дистанция, время, средняя скорость
- 🖼️ Экспорт коллажа (PNG) в галерею
- 📁 Экспорт GPX-трека (совместим с OsmAnd, Strava, Google Maps)
- 🎬 Экспорт MP4 через FFmpeg (требует NDK 26.1+)
- 🔋 Foreground Service — работа в фоне без убийства процесса
- 🌙 Тёмная/светлая тема (Material 3)

## Быстрый старт

```bash
flutter pub get
flutter run
```
